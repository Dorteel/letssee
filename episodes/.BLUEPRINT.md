# Episode integration

The `episode_builder` node in `/memory` maintains open scene accounts and commits closed ones. It depends on the vault writer, read access to committed records, schema 1 capture, percept and attempt readers, and the clock metadata carried in the sources.

| ROS 2 interface | Role |
| --- | --- |
| `/vault/committed` · `mind_interfaces/msg/RecordCommitted` | Subscribe to hints carrying `record_id`, `folder` and `path`. Read percepts, attempts and metadata-only capture records from the supplied vault-relative path. Load episode records to reconcile earlier work. |
| `/vault/commit` · `mind_interfaces/srv/CommitRecord` | Send `record_id`, `folder="episodes"`, rendered `markdown` and empty `staged_assets`. Read `ok`, `path` and `error`. The writer publishes the committed record hint. |

| Parameter | Type | Default | Purpose |
| --- | --- | --- | --- |
| `scene_gap_s` | double | `30.0` | Split adjacent event intervals in the same setting when the observed gap exceeds this many seconds. |
| `close_idle_s` | double | `45.0` | Close a draft provisionally after this much elapsed steady time without relevant input. |
| `reconcile_s` | double | `60.0` | Rescan committed sources and episodes to recover missed notifications. |

On startup, reconstruct drafts and the map from anchors to published versions from the vault. Repeat reconciliation on the timer. Topic callbacks enqueue source paths. A worker serializes changes for the same account. A known departure closes a draft promptly. Idle closure records the end of available evidence and leaves the physical end of the encounter open. Replays use the source event clock for grouping.

During reconciliation, check gap and withheld capture manifests as well as the percepts that yielded usable observations. A gap may use the recorder's steady clock and boot epoch. Require an established alignment to the episode clock and a known relationship to the scene and sensor before citing a coverage limitation. Other gaps remain available through vault recall.

Allocate each derived ID from the inputs, predecessor if any and transform version using the vault convention. Keep the complete commit request across retries, including its original `recorded_at`. After an ambiguous timeout, check the destination by ID before retrying. Fresh evidence may produce a successor. Consumers retrieve episodes through vault recall and follow the stored evidence links.
