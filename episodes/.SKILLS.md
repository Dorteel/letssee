# Remembering an encounter

## Assemble

`assemble(percepts, attempts, coverage_manifests, settings) -> episode_drafts`

1. Extract acquisition intervals, clock domains, epochs, frame names and direct evidence from the committed notes. Compare decimal nanoseconds as integers only when both intervals have bounds and share a known domain and epoch, or a documented clock alignment establishes order within its error bounds. For an older record missing clock metadata, leave the time relationship unknown. Receipt time and note creation time cannot establish acquisition order. Group timed observations by an identifiable setting and a comparable clock. A camera frame name alone cannot establish that a moving robot is still looking at the same tray.
2. Within each setting, order disjoint intervals by event time. Keep overlapping intervals together and label their relative order unknown unless the sources explicitly establish it. Place an attempt's requested action, reported completion and observed consequences in separate timeline entries when available. A command receipt establishes that the command was received.
3. Start a new account when the setting changes, a source records a departure, or the gap exceeds the configured interval. An idle stream can close an account provisionally. Preserve the reason and any missing coverage. Include an untimed percept or attempt as unordered context only when a source explicitly ties it to this encounter. Otherwise preserve an unanchored percept in its own account. If no observation supplies a comparable interval, set the episode bounds to YAML null and describe the timeline as unordered. In a mixed account, derive bounds only from the comparable entries and identify which entries they cover.
4. Compose a short scene description from the cited percepts. Keep alternatives next to the event that raised them. From the first view, “the tray rim hides the right side of the blue vessel” is a possible interpretation. If a later view reveals a handle, attach that evidence to the later entry.

Inspect metadata-only captures when assessing coverage. Match the stream, scene context and comparable interval before adding a gap or withheld sample to `sources`. State what coverage was missing and why. Count acquisition bounds from timed observations separately from receive-side monitoring bounds. A gap without a reliable match remains discoverable as its own capture.

## Reconcile

`reconcile(draft, existing_accounts) -> commit_request_or_no_change`

Use a stable source link as the account anchor and retain it in replacements. Reconcile against the active account for that anchor. Compare the timeline, boundaries, source set and interpretation. Skip an unchanged account. For a newly arrived source that clearly belongs to a published encounter, commit the complete revised account and link its predecessor. If the evidence could belong to either of two visits, record the ambiguity with the new observation and keep the established visits distinct. Replayed input must yield the same record or find its existing successor. An unresolved pair of replacement heads should be presented together for review.

## Recall

`recall_scene(episode, question) -> cited_timeline_excerpt`

Select the entries that answer the question. Return their source links, the event-time interval if known and any gap or ordering qualification that affects the answer. For a question about why I moved the camera, follow the intention's exact source versions. A note might reach the vault well after its producer prepared it. Where the citations or durable timing evidence leave past availability uncertain, say so.
