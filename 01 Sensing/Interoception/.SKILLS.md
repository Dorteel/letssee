# Interoception skills

- **State snapshots**: every minute, write a compact snapshot (battery, temps, peak currents, active faults, CPU/GPU load).
- **Felt-state labels**: map raw readings to simple states (`rested`, `tired`, `strained`, `hot`, `hurt`, `impaired`) using thresholds kept in `00 Self/Body`. These labels make interoception usable in Episodes and Reflections.
- **Fault records**: every fault or error gets its own record, always salient, never decayed.
- **Trend detection**: weekly, look for slow drifts (battery capacity fading, a joint running hotter) and open a note in `00 Self/Body`.
