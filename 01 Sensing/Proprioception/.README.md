# Proprioception

Joint angles, velocities, IMU, odometry, localisation: where my body is and how it's moving. Organised `YYYY/MM/DD/`.

This is a very high-rate stream with low value per sample, so I store it sparsely: a pose summary every few seconds, and full-rate traces only around events (a fall, a slip, a skill attempt I'll want to learn from).

Its most important job in memory is to *anchor* the other senses. Every visual or auditory record is taken from somewhere, and this is how I know where.
