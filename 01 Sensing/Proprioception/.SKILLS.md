# Proprioception skills

- **Pose summaries**: every few seconds, write base pose, map/place, and a compressed joint-state summary.
- **Event traces**: keep the full-rate trace for ±5 s around falls, collisions, slips, and every skill execution.
- **Drift detection**: compare odometry with localisation; when drift is large, flag it, because it affects trust in every spatially anchored memory from that period.
- **Place tagging**: attach the current place (link into `03 Understanding/Places`) to the record.
