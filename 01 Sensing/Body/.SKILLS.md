# Ingest body telemetry

1. Read the device identifier, session, sequence numbers, channel labels and firmware or calibration revision supplied with the packet. Use that identity to find any earlier ingestion of the same range.
2. Copy the packet file unchanged, or transcribe a short series with its original ticks, values, units and device flags. Keep the units and reference frame for each channel. For an onboard estimate, retain the estimator's name or version when the packet exposes it.
3. Check for sequence gaps, resets, saturation and device error flags. Record the affected ticks. A recorded zero remains a value. A missing tick becomes a gap. Keep averaging, interpolation and unit conversion in a derived note with a link to the original range.
4. For a file, verify the stored byte count and SHA-256 against the received payload. Reuse an identical ingestion. If a second payload claims the same sequence with different values, keep both and flag the discrepancy. Add the telemetry note to the enclosing capture's sources.

## Implementation interface

```text
record Telemetry(device, session, sequence, ticks, channels, payload, calibration, flags)
ingest_telemetry(packet: BodyPacket, channels: List<ChannelDefinition>, store: Vault) -> Telemetry
```
