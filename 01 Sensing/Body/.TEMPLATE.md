# Body telemetry

## Acquisition

Record the device and body location, session, sequence range, device clock and ticks, firmware and calibration reference.

## Channels

| Channel | Measurement, setpoint or onboard estimate | Original unit | Reference frame or zero |
| --- | --- | --- | --- |
| | | | |

## Received readings

Link the original file with its extension, byte count and SHA-256, or enter each tick, channel, value and device flag for a short series.

## Quality flags

Record missing ticks, resets, out-of-range values and sensor faults with the range affected.
