# Assemble a capture

1. Take a recording interval and its expected devices from the acquisition log. Locate the sample and telemetry notes by device, session and sequence. Reuse their links when processing the same interval again.
2. Choose the reference clock recorded for the session. For each stream record its original tick range and, when measured, its offset, drift and timing error against that clock. Map only the portion for which the relationship is known. Mark an unaligned stream in the table so a later reader can still inspect it.
3. Put each contributing note in `sources` as a quoted wikilink. In the coverage table give the sequence range or file offset covered by the interval. Account for expected devices with no records, lost packets and clock resets in the gaps section. If receipt time is the only timestamp, label it as receipt time.
4. Check the first and last sequence against the source and confirm that each link resolves. Where timing error could reverse the order of two readings, preserve both ranges and mark their order as unknown. A percept can cite this capture together with the source range it used.

## Implementation interface

```text
record Capture(session, interval, reference_clock, stream_ranges, timing_errors, gaps)
assemble_capture(interval: AcquisitionInterval, streams: List<Sample | Telemetry>,
                 clocks: List<ClockAlignment>) -> Capture
```
