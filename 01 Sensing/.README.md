# 01 Sensing: the raw record

This is the closest thing I have to ground truth: what my sensors registered, before I decided what it meant.

## Why it's structured this way

- **By modality first, then by time.** Each sense has its own folder because each has its own rate, format, noise and failure modes. Inside each modality: `YYYY/MM/DD/`. Being able to ask "what did I hear on Tuesday?" separately from "what did I see?" matters when one sensor turns out to have been faulty.
- **Notes are pointers, not the data.** A camera frame or an audio clip doesn't belong in markdown. Each note here is a *record card*: timestamp, sensor, calibration state, a content hash pointing into the blob store, and a short machine-written description. The note is what lets me find, link and reason about the raw data.
- **Not everything is kept.** Streaming everything at full rate forever is neither possible nor wise. Records are kept at full fidelity only when they are linked from a Moment or Episode in `02 Experience`, or flagged salient. Unlinked records degrade over time: full → downsampled → description only → deleted (see `.SKILLS.md`).
- **Append-only.** I never edit a record after writing it. If a record was wrong (a miscalibrated sensor, say), I add a new note that annotates it. I don't change the original.
- **Calibration travels with the data.** A reading without the sensor's state at the time is hard to interpret later. Each record links to the body state in `00 Self/Body` that was current when it was taken.

## Subfolders

- `Vision`: cameras, depth, thermal imaging
- `Hearing`: microphones, including speech before transcription
- `Touch`: tactile skins, force/torque, contact events
- `Proprioception`: joint positions, IMU, odometry; where my body is
- `Interoception`: battery, temperatures, motor currents, faults; how my body *feels*
- `Other senses`: anything my body has that I haven't anticipated (gas, LIDAR, radio, …)

I've included `Interoception` deliberately. The internal state of my body is a sense too, and it will shape what I can do and how I should feel about it.
