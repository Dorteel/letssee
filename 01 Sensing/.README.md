# Sensing

A capture note answers “what reached my sensors during this interval?” Keep the note here and the individual stream records in the two folders below. A capture can contain a single reading, a burst across several devices, or an interval in which a device was expected to report and stayed silent.

| Folder | What goes there |
| --- | --- |
| `External/` | Camera frames, sound, touch and other measurements of the surroundings, each with a sample note |
| `Body/` | Joint encoders, motor current, battery, temperature and other measurements of the robot itself, each with a telemetry note |

Use one bounded interval per capture. Start a new one when a recording session restarts or the reference clock changes. Link the stream notes in `sources` and identify the part of each stream covered by this capture. Keep the stream's original time labels even when a shared clock is available. Later percepts in `02 Experience/Percepts/` can then point to the exact moment they interpret.
