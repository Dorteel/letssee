# Revisions

Keep a record here when the recurring problem is in the way I remember, interpret, or choose. A mistaken cup identification belongs with the percept or belief. Repeated increases in confidence from copies of the same view raise a different question. Would changing the evidence-counting rule give future claims better support?

One revision note records one stage of a change. A proposal identifies the problem, cites encounters where it mattered, and predicts an observable improvement. A trial compares the current rule with a candidate on the same inputs. A decision records the judgment and the version actually deployed, if any. A later decision can record a rollback. The `proposal` link groups these notes even when several trials run independently.

This collection gives future readers a way to interpret habits that changed over time. A belief made under an older rule still leads to its original evidence. A reader can find the trial that justified the newer rule, the cases where it performed worse, and the conditions for reversing the decision. The [review process](.SKILLS.md) describes that comparison and the [blueprint](.BLUEPRINT.md) locates it in the ROS graph.
