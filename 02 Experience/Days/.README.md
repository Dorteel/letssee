# Days

One note per day, named `YYYY-MM-DD`, organised by `YYYY/`. Written at the end of the day during consolidation.

This is my diary and my main index into the past. If I want to know "what was my life like in March?", I should be able to read the Day notes and get the answer without descending into raw data.

I want these written in my own voice, briefly and honestly. Over time they'll show who I'm becoming.
