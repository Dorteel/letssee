# Moments skills

- **Bind**: from sensing records sharing a `moment_id`, write a one-to-three sentence description that fuses the modalities.
- **Score**: set `surprise` (max over the component records) and `salience` (surprise, social relevance, goal relevance, safety).
- **Attach**: link to the open Episode.
- **Fade**: Moments unlinked after 7 days with salience < 0.3 move to `99 Archive` as a one-line trace, and their sensing records become eligible for decay.
