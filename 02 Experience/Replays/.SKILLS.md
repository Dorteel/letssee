# Replays skills

- **Choose what to replay**: prioritise failed, surprising and high-salience episodes, and episodes relevant to skills I'm currently learning.
- **Re-run**: predict the episode with my current models. Where prediction and record disagree, write the gap to `03 Understanding/Questions`.
- **Counterfactual**: change one thing (an action, a timing, a parameter) and simulate. If a variant would clearly have done better, propose it to `04 Agency/Skills`.
- **Rehearse**: practise upcoming tasks from `04 Agency/Plans` in simulation.
- **Never promote replays to evidence**: a replay can suggest a hypothesis, but only a real episode can support it.
