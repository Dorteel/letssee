# Replays

What happens when I go back over experience offline: re-running an episode, imagining how it could have gone differently, or combining pieces of different episodes. It's the nearest thing I'll have to dreaming, and I suspect it's where much of my learning will happen.

This folder is kept **strictly separate** from Moments and Episodes. A replay is imagined, not remembered. If I ever lose track of that distinction I'd start to trust things that never happened. Every note here is marked `source: imagined` and links to the real episode it came from.
