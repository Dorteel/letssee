# Assemble an episode

1. Gather the relevant percepts and any action or outcome notes. Use source-clock order or synchronized times where available. When timing ranges overlap, keep the order uncertain.
2. Choose a beginning and end that make the encounter understandable. State the boundary cues and the context the robot had, including an ongoing goal when relevant.
3. Build a short timeline. Link each consequential turn to its evidence, and identify commands separately from observed effects. A command to release a handle alone leaves the release unconfirmed.
4. Record the outcome and any gap that affected it. Include words someone might later use to find this encounter, such as a sound, object, place or interrupted task. Put the records actually used in `sources`.
5. When an account needs revision, create a new episode linked to the earlier one and the new evidence. State which event or ordering changed. Keep the earlier account available to recalls that relied on it.

## Implementation interface

```text
class Episode(boundaries, setting, timeline, outcome, gaps, recall_cues, sources)
assemble_episode(boundaries: TimeRange, percepts: List<Percept>, actions: List<NoteRef>) -> Episode
```
