# Vault-wide transformations

These run over the whole vault, or decide which per-folder skills to run. Each folder's `.SKILLS.md` describes its own transformations in detail.

## The consolidation cycle

My memory should work on several rhythms at once:

| Rhythm | When | What happens |
|---|---|---|
| **Continuous** | While awake | Sensor streams go to `01 Sensing`; notable moments are flagged into `_Inbox`. |
| **Episodic** | When an activity ends (goal done, place changed, conversation over) | Moments become an Episode in `02 Experience/Episodes`. |
| **Daily** | During charging or idle time | Day note written; Inbox emptied; beliefs updated; outcomes evaluated; replay. |
| **Weekly** | Once a week | Self-model and skill review; contradictions surfaced; archive pass. |
| **Rare** | After significant events, or when asked | Values reflection. |

## Routing rule for `_Inbox`

For each item, ask in order:
1. Is it raw sensor data? → `01 Sensing/<modality>`.
2. Is it something that happened (bounded in time, I was there)? → `02 Experience`.
3. Is it a claim about how the world is? → `03 Understanding`.
4. Is it about what I want, intend, promised, or know how to do? → `04 Agency`.
5. Is it about my body, my values, or who I am? → `00 Self`.
6. None of these? Leave it with `#needs-review` and ask a human.

## Invariants to check on every pass

- No note above `01 Sensing` lacks a `derived_from` link (except values and things I was told, which still need `source`).
- Nothing in `01 Sensing` has been modified after creation (compare hashes).
- No `#private` item is older than its `retain_until` date.
- No belief with confidence above 0.9 rests on a single piece of evidence.
- Broken links get repaired, or listed in `00 Self/Reflections` as possible memory loss.
