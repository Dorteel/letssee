# Building and maintaining a memory map

## Follow a memory in either direction

1. Start with the question in the words I would use to ask it. Choose an entry point by the evidence I need. A distinctive sound is a cue for a percept or an episode. A claim about what usually happens is a cue for a model.
2. Follow direct source links until I reach a measurement, a reported account, or a gap in the record. For a long recording, carry forward the interval or sample range that mattered.
3. Use backlinks to follow an episode forward into later thoughts, plans, and actions. Check successor links before relying on a conclusion. If two records disagree, keep links to both and describe what each can establish.
4. Write a map when the path is worth using again. Give each entry a one-line reason to open it. Record the outstanding question when a search ends at a gap.

## Decide what to write

A single encounter may yield just a sample and a percept. Create an episode when its sequence matters, a model when an expectation can be tested, and an action record when I actually attempt something. Each transition needs a reason and a link to its inputs. A replay or a thought experiment can suggest a test while retaining its origin as a recollection or an imagined event.

## Keep a map usable

Revisit a map when a linked explanation changes, a source becomes unavailable, or a search turns up a better entry point. Update its reading order. Annotate a gap where a removed source once supported a claim, and revisit the claim if its remaining support changes.

## Implementation interface

The signatures in these guides describe proposed operations. Each note type maps to its folder’s template. A `NoteRef` identifies a note by its unique stem. An evidence citation can pair the reference with a frame, interval, or passage in the body.

```text
class MapEntry(note: NoteRef, reason_to_open: Text)
class MemoryMap(cue: Text, entries: List<MapEntry>, open_question: Text)
build_map(cue: Text, entries: List<MapEntry>, open_question: Text) -> MemoryMap
direct_sources(note: NoteRef) -> List<NoteRef>
```
