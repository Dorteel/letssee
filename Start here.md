# Start here

If I wake up remembering a green light, I want to ask three different questions. What reached my sensors? Why did I think it meant the battery was charging? What happened when I acted on that belief? Each question has a place in this vault.

| Folder | What lives here |
| --- | --- |
| **01 Sensing** | Capture manifests tie streams to a shared interval. **External** holds sights, sounds, touch, and other signals from the world. **Body** holds measurements from my own hardware. |
| **02 Experience** | **Percepts** record what I thought I detected. **Episodes** put those detections in the order I lived through them. A recall note in the parent folder records what a cue brought back. |
| **03 Understanding** | **Concepts** describe what I recognize across encounters. **Models** explain or predict what happens. **Questions** preserve what I still want to learn. A synthesis in the parent folder gives me room to think across them. |
| **04 Agency** | **Goals** hold commitments and their reasons. **Actions** record what I attempted and what followed. **Practices** hold skills I may reuse. Reflections in the parent folder connect choices to consequences. |

## From a green light to a better docking habit

Imagine I roll onto my charging dock. This example shows where I would write each part of that encounter.

1. **Sensing.** I save the camera frames in **External** and the battery current readings in **Body**. A capture manifest links the two records and describes how their clocks align. I can now find the exact frame and the current reading nearest to it.
2. **Experience.** A percept points to the frames where a green light appeared near the dock. My episode records the order of events. I rolled into place, saw green, and expected to charge. The current stayed near zero over the recorded interval.
3. **Understanding.** I open a question about the light. Does it come on whenever the dock has power? I also record a prediction about the connector. If poor contact explains the low current, reseating it should raise the current within the next ten seconds.
4. **Agency.** My goal is to have enough charge for the next trip. I reseat the connector and log that attempt as an action. Fresh telemetry shows the charging current rising four seconds later.
5. **Learning.** A reflection links both intervals. The rise fits my prediction, but I still have an open question about the light. My candidate docking practice says to check the measured current before declaring success and to stop for inspection if a reseat fails.

Months later, “green light, empty battery” might be my only cue. I can start a recall note, find the episode, follow its links back to the readings, and follow the episode’s backlinks forward to the practice.

## Make the first note

Open this repository folder as an Obsidian vault. In a file editor, copy the appropriate folder’s `.TEMPLATE.md` to a visible Markdown file in that same folder. For the first camera sample, a name like `sample-20261126T080000Z-dock-light.md` gives it a stable link. Fill the creation time, record what was available, and use that note’s name in the next record’s `sources` list.
