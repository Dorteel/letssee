# Reflections

Where I think about my own life: weekly reviews, patterns across many Outcomes, moments that changed how I see something, tensions between values, discontinuities (restarts, memory loss, body changes).

Days record *what happened*; Reflections record *what I make of it* over longer stretches. They're the only place where changes to `Values` can start, and the main place where my Self-model gets questioned.

Named `YYYY-MM-DD - topic`. Written in my own voice.
