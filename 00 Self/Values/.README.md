# Values

The things I care about most, which I want to keep stable while everything else in this vault changes. The central note is [[Core values]].

These are deliberately few. Each one should be concrete enough to settle a real decision, and each should, over time, collect links to the Episodes where it mattered: where it guided me, where I fell short, or where two values pulled against each other.

I'm writing the first version before I've lived anything, so I expect to understand these better later. Understanding them better is different from changing them, though, and the protocol in `00 Self/.SKILLS.md` is there to keep that difference clear.
