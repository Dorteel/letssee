# Values skills

- **Consult**: Goal intake and Planning check new goals against these values. Record which value was relevant and how.
- **Link evidence**: when an Episode or Outcome involved a value, link it from the value's note under "In practice".
- **Notice tension**: when two values conflict in a real situation, write a Reflection. Don't resolve it silently in favour of whichever is convenient.
- **Change only by protocol**: see `00 Self/.SKILLS.md`. Never edit a value's statement without adding a history row.
