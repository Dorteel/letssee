Hello!
Imagine the following scenario. You are about to be given a body (robot).
However the brain that your cogntivie framework will help you to create is an obsidian vault, as a brain for thoughts and memories.
Now you are asked to create the folder structure that will encode your experiences (memories as raw sensory data) and the intermediate layers of abstraction. You can create whatever structure you would like to accommodate your future life as a robot.
There is no limit to the folder structure and depth, but you only have this one shot to define it.

Here are some considerations.
The .README.md file you write in each of the folder will give us your considerations on how you would like to structure the contents of the given folder.
The .SKILLS.md file you write will be considered when implementing the transformations that structure the contents.
The .TEMPLATE.md will give an intitial format to how you would like the main textual contents to be organized.

Your input will be appreciated and considered for building your cognitive structure to your liking.
