# ROS 2 capture path

`/sense/recorder` subscribes to the driver topics below. It checks the recording scope, samples each stream on an independent schedule and passes the selected messages to a bounded worker queue. Serialization, hashing and file I/O run off the subscription callback. The subscription uses the ROS sensor-data QoS profile, which permits best-effort delivery with volatile history. [ROS 2 QoS profiles](https://github.com/ros2/rmw/blob/rolling/rmw/include/rmw/qos_profiles.h)

| Publisher → recorder | Interface | Sample retained |
| --- | --- | --- |
| Camera driver on `/camera/image_raw` | `sensor_msgs/msg/Image` | Acquisition header, dimensions, encoding, stride and pixels in a single message. [Image definition](https://github.com/ros2/common_interfaces/blob/rolling/sensor_msgs/msg/Image.msg) |
| Joint-state driver on `/joint_states` | `sensor_msgs/msg/JointState` | Acquisition header, joint names and populated measurement arrays. [JointState definition](https://github.com/ros2/common_interfaces/blob/rolling/sensor_msgs/msg/JointState.msg) |

The deployment maps each driver to its clock domain, epoch source and recording permission. Remap the topic names to the installed drivers. Increase the clock epoch identifier after a reset when an old timestamp range could recur. A standard header carries a timestamp and frame ID, so these extra clock facts come from the driver configuration or its clock monitor. When the monitor has a valid alignment, retain its version and the earliest and latest plausible UTC times in the manifest. These bounds include the calibration error in that epoch and remain available for later comparison with body results.

The worker requests `/vault/commit` (`mind_interfaces/srv/CommitRecord`) with `record_id`, folder `captures`, Markdown and an ordered list of staging tokens for the listed assets. A metadata-only record sends an empty list. On `ok`, keep the returned path as the acknowledgement. On a transient failure, retain the draft for retry. A persistent error, such as a digest mismatch, calls for inspection. On startup, reconcile pending drafts with committed manifests and resume interrupted deliveries. The vault writer announces each durable record on `/vault/committed`.

| Recorder parameter | Type | Default | Meaning |
| --- | --- | --- | --- |
| `sample_period_ms` | integer | 1000 | Minimum interval between retained samples on each active stream. |
| `silence_timeout_ms` | integer | 2000 | Steady-clock delay after the last received input before flagging a possible outage on a monitored periodic stream. |
| `queue_capacity` | integer | 16 | Maximum number of selected messages awaiting the worker. Count discarded arrivals when the queue fills. |

Sensor drivers, their message definitions, the clock mapping, recording permission and the writer's staging area are dependencies. A policy or staging failure during an outage may leave its duration unknowable. Mark the uncovered portion as unknown when recording resumes.
