# Belief integration

The `belief_reviewer` node in `/memory` discovers candidate claims in episodes and revisits existing claims when their evidence changes. It depends on the vault writer, committed record access and a rebuildable index over claim keys, source links and replacement links.

| ROS 2 interface | Role |
| --- | --- |
| `/vault/committed` · `mind_interfaces/msg/RecordCommitted` | Subscribe to hints containing `record_id`, `folder` and `path`. Read episodes and relevant percepts or attempts. Use incoming belief records to refresh the claim index. |
| `/vault/commit` · `mind_interfaces/srv/CommitRecord` | Send `record_id`, `folder="beliefs"`, complete `markdown` and empty `staged_assets`. Read `ok`, `path` and `error`. The vault writer announces successful commits. |

| Parameter | Type | Default | Purpose |
| --- | --- | --- | --- |
| `reconcile_s` | double | `60.0` | Rescan the vault for evidence and assessment changes missed by the subscriber. |
| `review_batch_size` | integer | `16` | Limit the number of claim keys reviewed per worker cycle. Leave the remainder queued. |

At startup, scan current and superseded records to rebuild the evidence index. A new episode can introduce a claim or supply evidence about an existing subject. A corrected percept can invalidate downstream support even when the corrected note describes a different object. Follow the predecessor's backlinks as well as the new note's subject. Use belief notifications to update the index without scheduling the same belief as fresh evidence about itself.

Serialize reviews for the same claim key. Before committing, recheck the current head and recompute the assessment if another review has landed. Use the vault's stable derived ID convention over the claim key, evidence set, assessment version and predecessor. Preserve the request across retries. After an unknown commit outcome, look up the ID before retrying. Distinct heads found during reconciliation remain visible together until reviewed. Vault recall supplies the records for use by the planner and for historical questions.
