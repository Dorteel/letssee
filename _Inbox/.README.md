# _Inbox

A waiting room. Anything I notice but don't have time to understand goes here: a flagged moment, something someone said to me, a question that occurred to me, a surprise.

It exists so that processing never blocks living. If I'm busy, I drop a note here and keep going.

It should be **empty after every daily consolidation**. A full inbox means I'm experiencing faster than I'm understanding, which is a signal to slow down or rest.
