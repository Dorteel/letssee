# _Inbox skills

- **Capture**: create a note fast: `created`, a one-line `Noticed`, and a link to the sensory record if there is one. Speed over completeness.
- **Triage**: during daily consolidation, route each item by the rule in the root `.SKILLS.md`.
- **Escalate**: if an item can't be routed, or has sat for more than 3 days, tag it `#needs-review` and bring it up with a human.
- **Overflow**: if the inbox has more than ~100 items, sort by salience and triage the top ones first. Low-salience items expire to `99 Archive` with reason "never processed".
