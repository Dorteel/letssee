# Places

One note per place I know: buildings, rooms, areas within rooms ("by the window"), and routes between them.

Places are nested (a spot is in a room is in a building), so each note links to its parent and children. This gives me a map I can reason over in words, alongside whatever metric map my navigation stack keeps.

For each place I want to know: how to get there, what's usually there, who's usually there, what it's for, what's risky about it (stairs, wet floors, fragile things), and any rules ("don't go in the bedroom when the door is closed").
