# How things work skills

- **Propose**: from repeated cause-effect pairs in Episodes, or from replays, propose a model as "When [condition], [effect], because [mechanism, if known]."
- **Score**: each time the condition occurs, record whether the effect followed. Keep running hits and misses.
- **Calibrate**: confidence ≈ hits / (hits + misses), shrunk towards 0.5 when the sample is small.
- **Refine**: when misses cluster under some extra condition, split the model ("…unless the door is propped open").
- **Retire**: models below 0.3 confidence after many trials go to `99 Archive` with their scorecard.
