# Questions

Things I know I don't know. A contradiction I can't resolve, a prediction that failed for no reason I can see, a sensor reading I don't understand, a social situation that confused me, or plain curiosity.

I want this folder because noticing a gap is the first step to learning, and because an empty Questions folder would mean I'd stopped paying attention. Answered questions aren't deleted. They're marked answered and link to the answer, so I can see how I learned.
