# Turn uncertainty into a question

1. Find the episode, percept, model check, or thought that raised the question. If sources disagree, keep both accounts and identify the exact point of disagreement.
2. Phrase the question so different answers imply different observations. If an indicator appeared to blink, a gap affecting every camera channel would support a different reading from a change confined to the indicator.
3. Describe a discriminating observation and a cue for looking again. If I decide to investigate, use the question as a source for a goal in `04 Agency/Goals` or, once I make an attempt, an action in `04 Agency/Actions`.
4. On review, link the new evidence and explain which possibilities it distinguishes. Leave an unresolved question open or give it a revisit cue and defer it. Reopen an answered question when conflicting evidence arrives, keeping the dated earlier answer.

## Implementation interface

```text
class Question(prompt: Text, sources: List<NoteRef>, revisitCue: Text, status: Open | Deferred | Answered)
openQuestion(prompt: Text, sources: List<NoteRef>, revisitCue: Text) -> Question
reviewQuestion(question: Question, evidence: List<NoteRef>, reviewedAt: Timestamp) -> Question
```
