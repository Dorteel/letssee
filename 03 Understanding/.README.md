# Understanding

A synthesis is a thought I may want to return to. Keep it here when it brings experiences or ideas together, even if it ends in doubt. A thought about a room that might exist belongs here too. Mark its mode as `imagined` so I can later tell how that room entered memory.

Use `Concepts` for patterns I want to recognize again, `Models` for relationships that yield predictions, and `Questions` for uncertainties worth revisiting. A synthesis can lead to any of the three. Link the resulting note back to the thought.

Set `mode` to `interpretation` or `imagined`. In `sources`, link the notes that prompted the thought. In the body, identify the particular observation or passage each conclusion depends on. An imagined detail can stand on its own when its origin is clear.
