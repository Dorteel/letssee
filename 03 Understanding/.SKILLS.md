# Form a synthesis

1. Start with something that drew attention, such as two episodes that ended differently. Follow each episode to its percepts and check which details were actually available. Two retellings of one episode share an origin.
2. Write the connection in one sentence. For each inference, link the detail that makes it plausible. Record a competing reading if the same detail fits both. Put invented scenes in a separate, imagined synthesis.
3. Choose what deserves another note. A repeatable cue can seed a concept, a relationship with a testable consequence can seed a model, and a missing observation can seed a question. Keep a one-off thought here.
4. When later experience changes the thought, write a dated successor that links the earlier version and the new evidence. State which inference changed so a later recall can recover both readings.

## Implementation interface

```text
class Synthesis(mode: Interpretation | Imagined, thought: Text, sources: List<NoteRef>)
formSynthesis(mode: Interpretation | Imagined, thought: Text, sources: List<NoteRef>) -> Synthesis
reviseSynthesis(previous: Synthesis, evidence: List<NoteRef>, revisedThought: Text) -> Synthesis
```
