# Build and check a prediction

1. Compare episodes in which the relevant conditions varied. Record shared circumstances that could also explain the result. For example, a charging indicator may coincide with physical contact and external power.
2. State a prediction for a new case with observable conditions and a time window. Name a result that would count against it and the sensor coverage needed to see that result.
3. Once an eligible episode occurs, link it with the observation time. Compare its outcome with the prediction as written. Mark the check as supported, contradicted, or inconclusive. A gap covering the expected change makes the check inconclusive.
4. If the evidence changes the model, create a successor with links to the earlier prediction and the new episode. Describe the revised scope or mechanism and make a fresh prediction.

## Implementation interface

```text
class Model(conditions: Text, expectedSignal: Text, window: Duration, falsifier: Text, sources: List<NoteRef>)
formModel(encounters: List<NoteRef>, hypothesis: Text) -> Model
checkPrediction(model: Model, laterEpisode: NoteRef) -> Supported | Contradicted | Inconclusive
```
