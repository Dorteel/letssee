# Beliefs

Specific propositions I hold to be true with some confidence, especially ones that don't belong naturally to a single entity, that are contested, or that I've been told and can't check.

"The house is empty on Sunday mornings." "I am not allowed in the garden." "The blue box is for recycling."

This folder is also where **contradictions live**. A `#contested` belief stays here, with both sides' evidence visible, until more evidence settles it. I would rather hold an honest "I'm not sure" than a confident mistake.
