# Concepts skills

- **Form**: when the generalisation pass finds a recurring pattern across Things, Places or Episodes, propose a Concept with its defining features and examples.
- **Ground**: every Concept should have at least one link to a real instance. Concepts I hold only in the abstract get tagged `#ungrounded`.
- **Relate**: link concepts to broader ones (is-a), parts (has-a), and opposites.
- **Revise**: when an instance doesn't fit, add it under "doesn't fit". If misfits accumulate, revise the concept and log the change.
