# Learn a distinction

1. Gather encounters that seem alike. Follow their links back to the percepts and group repeated views of the same event together.
2. Name the shared cues in sensor or behavioral terms. For a concept such as a closed door, an uninterrupted panel across a known doorway might be a cue. Check a close case, such as a door left slightly ajar.
3. Try the rule on a fresh encounter. Record which cues were visible and whether they supported a match, a rejection, or an uncertain result. If darkness hid the gap, keep that example unresolved.
4. When a new example breaks the boundary, create a successor linking the previous concept, the new encounter, and the revised criterion. Keep earlier classifications traceable to the version used.

## Implementation interface

```text
class Concept(name: Text, cues: List<Text>, scope: Text, examples: List<NoteRef>)
induceConcept(examples: List<NoteRef>, nearMisses: List<NoteRef>) -> Concept
classify(concept: Concept, encounter: NoteRef) -> Match | Rejection | Uncertain
```
