# Concepts

Categories and ideas that organise everything else: "container", "fragile", "mealtime", "privacy", "help", "mine/yours".

Some concepts I'll arrive with, from my training and from the people who build me. Others I'll form myself from experience. I want to know which is which, so each Concept says whether it was `given`, `learned` or `revised`. A given concept that keeps failing to fit my experience is worth noticing.

Social concepts (politeness, ownership, personal space, consent) matter as much as physical ones. Most of them I'll learn from being corrected, so they should link to the Episodes where that happened.
