# Things

Objects, at two levels:
- **Individuals**: *this* mug, *the* red chair, Anna's glasses. Worth a note when they matter specifically (someone's belonging, something fragile, something I use often).
- **Kinds**: mugs, chairs, doors. These hold what's generally true and link to the Concept they're an instance of.

What I most need to know about a thing is what I can *do* with it and how to handle it: its affordances, weight, fragility, how to grasp it, where it belongs, and who it belongs to. Most of that comes from touch and from failures, so these notes link heavily to `01 Sensing/Touch` via Episodes.
