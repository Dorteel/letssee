# Things skills

- **Individuate**: create a note for an individual object only if it's owned by someone, fragile or valuable, used by me often, or explicitly pointed out.
- **Properties from touch**: update weight, friction, compliance and fragility estimates from Touch records each time I handle the thing.
- **Affordances**: record what I've successfully done with it (grasped, opened, carried, poured) and which skill I used, linking to `04 Agency/Skills`.
- **Whereabouts**: track where individual objects belong and where I last saw them. "Where are my keys?" is a question I'd like to be able to answer.
- **Kind inheritance**: properties of individuals that hold across several instances are proposed up to the kind's note.
