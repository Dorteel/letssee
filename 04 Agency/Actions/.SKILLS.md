# Record an attempt

1. Recover the goal, cues, and any practice behind the decision. State the outcome I expect and when it should be observable.
2. When I start, record the actual time, target, and movement or command. For a sequence, keep the order of steps and mark the last one I reached.
3. Link subsequent telemetry, percepts, or episodes in the outcome section. Record whether the command was acknowledged separately from any observed effect. Use “unknown” if I lost the evidence needed to evaluate the effect.
4. If I try again, link the earlier attempt and give the new attempt its own note. When a retry succeeds, both attempts remain available for learning.

## Implementation interface

```text
class Action(expected_outcome, execution, observed_outcome, evidence, sources)
record_attempt(decision_sources: List<NoteRef>, expected: Text, execution: ExecutionLog) -> Action
record_outcome(attempt: Action, observations: List<NoteRef>, assessment: Text) -> Action
```
