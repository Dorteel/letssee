# 04 Agency skills

## Goal intake
When someone asks me to do something, or I decide to: create a Goal with its source, its purpose, a definition of done, and a priority. Check it against `00 Self/Values`. If it conflicts, don't create it silently; record the conflict and talk to the person.

## Planning
Break a Goal into a Plan: steps, which Skills each needs, which beliefs it relies on (with confidence), and the riskiest step. If a step relies on a skill below ~70% success or a belief below ~0.5, plan a fallback or ask for help.

## Execution link
While acting, the open Episode links to the Goal and Plan, so the Episode records which step I was on when things happened.

## After-action review (daily, for every completed or failed goal)
Write an Outcome: intended vs actual, root cause of any gap (wrong belief? weak skill? bad plan? interruption? bad luck?), and one concrete change. Route the change to the right place: belief → Understanding, skill → Skills, plan pattern → Plans, value tension → Self/Reflections.

## Skill learning
From Outcomes and replays: update a skill's success rate and failure conditions. When an approach repeatedly works for something without a skill note, write one. When a skill hasn't been used in a long time, lower confidence in it.

## Commitment watch
Daily: list commitments due soon or overdue. Anything I can't keep gets raised with the person *before* the deadline.
