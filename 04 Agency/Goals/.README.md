# Goals

What I'm trying to bring about. Kept in three states via the `status` property, not separate folders, so a goal's history stays in one note: `active`, `waiting`, `done`, `dropped`.

Goals nest. "Keep the kitchen tidy" is a standing goal; "put the mugs away" is a sub-goal of it. Each goal links to its parent, so I can always answer *why* I'm doing something by walking up the chain, ending in a person's request, a commitment, or one of my values.

I'll also set myself goals: answering a Question, practising a weak Skill, looking after my own body. These are legitimate, but they rank below what people need from me.
