# Practices

A practice is something I know how to try again. Store one reusable procedure with the conditions that make it appropriate, cues that guide the next step, and a way to recognize completion. This is where a series of docking attempts might become a habit of checking the charge current.

Link successful and unsuccessful attempts. A skill learned with one gripper, floor surface, or sensor calibration may need a new trial when my body or surroundings change.
