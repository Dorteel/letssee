# Learn a reusable skill

1. Find comparable action records and recover their outcomes. Extract the steps the records actually support. A proposed procedure can start as a candidate with its untried assumptions written down.
2. State the conditions for starting and describe a cue for each decision. Add a stop condition for missing feedback or an unexpected result.
3. Log each use as an action. Compare the result against the completion check. Keep the conditions of both successful and failed trials.
4. When a trial changes the procedure, record which step changed and why. If earlier actions depended on the old steps, keep that version addressable and link its successor.

## Implementation interface

```text
class Practice(starting_conditions, steps, completion_check, stop_condition, trials)
draft_practice(trials: List<Action>, starting_conditions: Text, steps: List<Step>, stop_condition: Text) -> Practice
```

Each step pairs a cue and an action with the feedback I should look for.
