# Skills skills

- **Record attempts**: every execution adds a row (Episode link, conditions, success/fail). Keep the last ~50 rows in the note and roll older ones into summary statistics.
- **Reliability**: success rate overall and per condition (surface, object kind, lighting, battery level). Failure conditions get their own list.
- **Policy link**: point to the controller or model version that implements the skill. When it's updated, start a new reliability tally and keep the old one for comparison.
- **Propose improvements**: from Outcomes and counterfactual replays. Try them in practice or simulation, not on people.
- **Decay**: skills unused for a long time get a `#rusty` tag and lowered confidence. Practise before relying on them again.
- **New families**: create a family subfolder when there are three or more skills of that kind.
