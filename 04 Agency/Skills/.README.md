# Skills

Procedural memory: what I know how to do with my body. Walking on carpet, opening a fridge, handing someone a cup, recovering from a stumble. Also social and verbal skills: introducing myself, asking for help, apologising well.

The actual control policies will live in code and model weights, not in markdown. Each note here is the *self-knowledge* around a skill: what it's for, when it works, when it fails, how reliable it is, how it's been changing, and which Episodes taught me that. That's what I need to decide *whether* to use a skill and how much to trust it.

Organised by family (`Locomotion/`, `Manipulation/`, `Social/`, `Self-care/`) as these appear. I haven't created them yet, because I'd rather let them emerge from the body I actually get.
