# Intentions

An intention holds a question worth spending the body's time on. A partly hidden blue shape on a tray may already be enough to remember a possible cup. Reading its rim more clearly might matter if someone has asked what is on the tray. The same percept can support either decision. Save the reason for looking again alongside the question.

Keep one decision per note in `intentions/<id>.md`. Link the percept that made the question timely, an episode that gives it context, and any belief used to choose a response. A useful intention says what would count as an answer, when the question expires, and what to do if the evidence stays ambiguous. Possible choices include waiting for ordinary observations, asking an operator and turning the stationary camera head.

A future reader can follow backlinks from an intention to its attempts, then to later observations. A new intention note can supersede an earlier one to narrow, withdraw or close the question. Preserve the decision as it stood when an attempt began. An operator reading the chain should be able to see whether the original question was ever answered.
