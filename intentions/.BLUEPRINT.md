# Deliberation in ROS 2

`/agency/planner` reads the vault and owns intention notes. To ask a question, the operator uses the local interface to commit a root orientation note with `purpose: inquiry`. Its title supplies the question, its body gives the motive, and its sources link the relevant observations if known. For example, an operator identifying items on the tray can ask whether the blue patch belongs to a cup. The planner can turn that orientation and a matching percept into an intention naming both sources.

The planner subscribes to `/vault/committed` (`mind_interfaces/msg/RecordCommitted`, fields `record_id`, `folder`, `path`). A new inquiry or a matching percept prompts consideration. Handoffs serve readers resuming a question. An attempt assessment or later percept can resolve the question. On each trigger the planner reads the named file and the current decision chain. It can reconstruct open questions by scanning committed notes on startup and at the shared reconciliation interval. Deduplicate by the orientation ID, the decision being revisited, the rule version and the exact input IDs so a scan of the same evidence yields the existing note.

The planner submits the full note to `/vault/commit` (`mind_interfaces/srv/CommitRecord`) with `record_id`, `folder=intentions`, `markdown` and empty `staged_assets`. It checks `ok`, `path` and `error`. Retrying a write uses the same ID and bytes. Fresh look candidates expire after `look_offer_ttl_s` (double, default 15.0 seconds). Measure this interval from the decision and cap the expiry at the validity limit of the pose and evidence. A candidate that already expired is recorded as a wait or referred to the operator.

The planner exposes the choice through the note. An operator interface can display open questions and their tests, then call the executor's live `/agency/try_look` service for a particular current intention. Deliberation, service admission and body feedback have separate lifetimes. A replay can reconstruct which choices were available at the time. See the [attempt interface](../attempts/.BLUEPRINT.md) for admission, cancellation and recovery.
