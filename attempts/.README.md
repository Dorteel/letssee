# Attempts

Keep the history of what the body was asked to do, how the body responded, and what was subsequently observed. These three facts often arrive at different times. All three matter when I later ask whether looking again bought me any information.

Store each event in `attempts/<id>.md`. The first note reserves an attempt for one version of an intention. Its note ID becomes the shared `attempt_id`. Record the body return and the assessment as new notes with their own IDs and the same `attempt_id`. Sources link each note to its direct inputs. A correction gets a new ID and a `supersedes` link to the erroneous note. A later phase in the same attempt keeps the earlier phase as evidence.

For example, the camera may report reaching the requested angle while the blue cup's rim remains behind the tray edge. The return note can say `reached` and the assessment can say `inconclusive`. Follow the assessment to the post-look percept, then to its raw capture to inspect the visible patch. The planner can now keep the question open. The episode builder can place the whole attempt beside the surrounding observations.
