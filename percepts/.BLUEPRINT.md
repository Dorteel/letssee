# ROS 2 perception path

`/sense/interpreter` subscribes to `/vault/committed` (`mind_interfaces/msg/RecordCommitted`). For each hint with `folder == "captures"`, read the manifest at the indicated vault-relative `path` and match its `id` to `record_id`. Read the declared capture asset, check its digest, and choose the decoder for its type and version. The camera interpreter reads `sensor_msgs/msg/Image`. The posture interpreter reads `sensor_msgs/msg/JointState`.

Process each eligible capture independently. An image can yield a claim in pixel coordinates and a joint-state message can yield a reading by joint name. A missing frame or unknown event stamp stays unknown in the percept. The interpretation worker takes its input from committed captures so a replay can inspect the same bytes. Only a worker permitted to handle the capture's recording scope may read those bytes or publish a derivative to this vault.

For each resulting claim, call `/vault/commit` (`mind_interfaces/srv/CommitRecord`) with the derived `record_id`, folder `percepts`, Markdown and an empty `staged_assets` list. Freeze the rendered draft and its creation timestamp through any retries. Verify `ok` and the returned `path`. Use `error` to distinguish a retry from an invalid record. Episode and memory workers discover the new record through the writer's next commit hint.

| Interpreter parameter | Type | Default | Meaning |
| --- | --- | --- | --- |
| `method_revision` | string | `tabletop-v1` | Pinned decoder, model, claim ordering and settings. Change the revision when any of these can affect a claim. |
| `reconcile_period_s` | integer | 30 | Interval between scans for captures that missed processing. Also scan at startup. |

Persist a processing receipt keyed by capture ID and method revision in rebuildable worker state after every resulting note has committed. A successful run with zero claims also earns a receipt. For a repeated run, calculate the same claim keys and check for already committed IDs before rendering any missing notes. Metadata-only captures can be marked processed immediately. Surface a damaged payload as a diagnostic and retry once the underlying read failure clears.
